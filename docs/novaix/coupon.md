# 优惠券 {#coupon}

Novaix 支持灵活的优惠券系统，您可以创建各种类型的优惠券来促进销售。

## 创建优惠券 {#create-coupon}

在管理面板的「优惠券管理」中创建优惠券，支持以下配置：

### 基本配置 {#basic-config}

| 字段 | 说明 |
|------|------|
| 优惠券码 | 用户在下单时输入的兑换码，支持手动输入或点击按钮随机生成 |
| 类型 | 固定金额减免 或 按百分比折扣 |
| 折扣值 | 减免金额或折扣百分比 |

::: tip 随机生成优惠码
点击优惠码输入框右侧的按钮，可随机生成一个 8 位大写字母+数字组合的优惠码，已排除易混淆字符（如 O/0、I/1/L）。生成后仍可手动修改。
:::

### 使用限制 {#usage-limits}

| 字段 | 说明 |
|------|------|
| 总使用次数 | 所有用户累计可使用的总次数 |
| 每人使用次数 | 单个用户最多可使用的次数 |
| 最低订单金额 | 订单金额达到多少才能使用 |
| 最大折扣金额 | 百分比折扣时的最大减免上限 |
| 生效时间 | 优惠券的生效开始时间 |
| 过期时间 | 优惠券的过期时间 |

### 适用范围 {#applicable-scope}

您可以分别设置优惠券适用的订单类型和套餐，订单需要同时满足两项限制。

| 字段 | 说明 |
|------|------|
| 适用订单类型 | 限制新购、续费等订单类型，选择「全部类型」时不限制 |
| 适用套餐 | 默认「全部套餐」。选择「指定套餐」后，可搜索并选择一个或多个套餐，最多 100 个 |

新购按购买的套餐判断，续费按实例当前套餐判断，升级按目标套餐判断。不在适用范围内的套餐无法使用该优惠券。

已有优惠券默认适用于全部套餐。复制套餐会生成独立套餐，不会自动加入原优惠券的指定范围，需要在优惠券中单独添加。

::: tip
修改适用套餐后，后续下单和支付会重新检查范围。待支付订单中的手动优惠码不再适用时，需要重新下单；持续折扣不再适用时，续费恢复正常价格。已支付订单的金额和历史使用记录保持不变。

已选套餐被删除后，优惠券仍保留原限制，不会自动变成全部套餐。编辑时如果只显示套餐编号，请核对后保留或移除；如需取消套餐限制，请明确选择「全部套餐」。
:::

### 折扣模式 {#discount-duration}

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 单次 | 折扣仅作用于当次订单（默认） | 促销活动、新用户首购优惠 |
| 持续 | 首次使用后绑定实例，后续续费自动享受折扣 | 长期合作折扣、渠道返利、VIP 客户专属价 |

**持续折扣的工作方式：**

1. 用户首次使用持续折扣优惠券下单并支付成功后，优惠券自动绑定到对应实例
2. 该实例后续续费时，系统自动应用相同折扣，无需再次输入优惠码
3. 自动续费时同样享受持续折扣
4. 续费时若用户手动输入了其他优惠码，以手动输入为准
5. 优惠券被禁用、过期或不再适用于实例当前套餐后，续费不再享受折扣，但不影响正常续费

::: warning
创建持续折扣优惠券时，适用订单类型必须包含「续费」，否则绑定后续费时无法生效。

持续折扣的使用次数限制仅控制首次使用（绑定）次数，绑定后的自动续费应用不计入使用次数。
:::

## 使用统计 {#usage-stats}

在优惠券列表中，您可以查看每个优惠券的使用次数和剩余可用次数，方便评估促销效果。

持续折扣优惠券的详情页还会展示当前绑定了该优惠券的实例列表。

## 删除与重新创建 {#delete-and-recreate}

删除后，优惠券会从管理列表中隐藏，不能继续用于新订单或持续折扣续费，历史订单和使用记录仍保留。

从 0.4.7 起，您可以重新创建相同优惠码，也可以将其他优惠券改为已删除的优惠码。重新创建会生成一张新优惠券，使用次数和每人限额独立计算；旧订单、旧使用记录和原有实例的持续折扣绑定不会转移到新券。尚未删除的优惠码仍不能重复，禁用或过期的券也仍占用原码。

## 注意事项 {#notes}

::: warning
- **优惠券码区分大小写**。建议统一使用大写字母和数字，避免用户输入时因大小写问题而无法使用
- 优惠券码创建后仍可修改，系统会自动检查新码值是否与其他优惠券冲突
- 如果优惠券设置了「最大折扣金额」，当百分比计算出的折扣超过此上限时，实际折扣以上限为准。例如：10% 折扣 + 最大折扣 50 元，用户购买了 1000 元的套餐，折扣应为 100 元，但实际只减免 50 元
- 已使用的优惠券即使被删除，也不会影响已生成的订单
- 如果您想暂停某个优惠券的使用，可以将其过期时间设为当前时间之前，而不必删除它
- 金额为 0 的订单（优惠券全额抵扣），用户前台仍需通过余额支付确认后进入开通流程；管理员后台代客下单默认自动支付
:::
