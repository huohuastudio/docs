# 实例转移 {#push-transfer}

实例转移（Push）允许用户将实例的控制权和未来计费责任转移给另一个用户。发起方生成一次性转移码，接收方输入转移码即可接收实例，无需暴露双方身份信息。

## 启用转移功能 {#enable}

转移功能默认关闭。在管理面板的「系统设置 → 实例转移」中启用：

| 字段 | 说明 |
|------|------|
| 启用实例转移 | 开启后，用户端将显示「实例转移」入口 |
| 手续费类型 | 无 / 固定金额 / 按比例。按比例时以实例当前计费周期的锁定价格为基数 |
| 手续费金额 | 固定金额（单位：分）或百分比（1-100） |
| 费用承担方 | 发起方或接收方 |
| 发起方需实名 | 开启后，发起转移的用户必须完成实名认证 |
| 接收方需实名 | 开启后，接收转移的用户必须完成实名认证 |
| 转移码有效期 | 转移码过期时长，单位为小时，默认 72 小时 |
| 保护期 | 实例创建后多少天内不允许转移，0 表示无限制 |
| 需要审批 | 开启后，接收方确认接收后需管理员审批通过才能完成转移 |

启用后，用户端导航会自动显示「实例转移」入口；关闭后入口自动隐藏。

## 转移流程 {#flow}

### 发起转移

1. 用户在「实例转移」页面点击「发起转移」
2. 选择要转移的实例，确认手续费信息
3. 系统生成 32 位转移码，用户将转移码发给接收方

### 接收转移

1. 接收方在「实例转移」页面点击「接收转移」
2. 输入转移码，系统展示实例概要信息（名称、配置、IP、到期时间等）
3. 确认接收后：
   - 如果未开启审批：转移立即完成
   - 如果开启了审批：进入「待审批」状态，等待管理员处理

### 管理员审批

开启审批后，转移请求在接收方确认后需要管理员操作：

- 在管理面板的「转移管理」页面查看待审批记录
- 点击「通过」完成转移，或「拒绝」取消转移并退还已收手续费

## 转移范围 {#scope}

- **转移内容**：实例控制权和未来计费责任（续费、升级等由新用户负责）
- **跟随实例**：IP 地址、快照、防火墙规则等通过实例 ID 关联的资源自动跟随
- **不转移**：历史订单和交易流水保留在原用户账户，不会迁移

## 限制条件 {#restrictions}

以下情况不允许发起转移：

- 实例状态不是「运行中」或「已停止」
- 实例有正在执行的任务（重装、升级等）
- 实例为按小时计费
- 实例已挂载到 VPC 私有网络
- 该实例已有进行中的转移请求
- 实例在保护期内（如配置了保护期）

## 取消与退款 {#cancel}

- **发起方取消**：在接收方确认前，发起方可随时取消转移，已扣手续费自动退还
- **接收方拒绝**：接收方可以拒绝转移请求，已扣手续费退还给实际付费方
- **自动过期**：超过有效期未被接收的转移请求自动过期，手续费退还
- **管理员拒绝**：审批模式下管理员拒绝后，手续费退还
